# US home values & rents

Interactive map of typical home values and rents across the United States, by ZIP code (Zillow, September 2026) or by Census tract (American Community Survey 2020–2024), on an OpenStreetMap street map (OpenFreeMap).

Open `index.html` through any static web server (GitHub Pages serves it as is).

Data: Zillow Research (ZHVI, ZORI), US Census Bureau (ACS 2020–2024 tables B25077 and B25064; 2020 ZIP Code Tabulation Areas; 2022 tract boundaries; 2024 Gazetteer). Map tiles: OpenFreeMap © OpenMapTiles, data © OpenStreetMap contributors.
